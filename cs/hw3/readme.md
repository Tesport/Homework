# Конспект по коду: LINQ и record

Данные из кода:

```csharp
record User(string Name, int Age, string City);
users   = Анна(25, Москва), Иван(17, СПб), Олег(30, Москва), Анна(20, Казань)
numbers = { 5, 2, 8, 2, 1, 9, 3 }
```

Все методы LINQ принимают последовательность и возвращают новую (исходная не меняется). Лямбда `u => ...` описывает, что делать с одним элементом.

---

## 1. Фильтрация

| Метод | Что делает | Что принимает |
|---|---|---|
| `Where(u => u.Age >= 18)` | Оставляет элементы, для которых условие `true` | `Func<T,bool>` |
| `Where((n, i) => i % 2 == 0)` | То же, но условие знает индекс элемента | `Func<T,int,bool>` |
| `OfType<string>()` | Оставляет только элементы указанного типа | тип в `<>` |
| `Cast<int>()` | Приводит все элементы к типу (если не подходит, будет ошибка) | тип в `<>` |

Результаты в коде:
- `Where` по возрасту: Анна(25), Олег(30), Анна(20)
- `Where` с индексом: 5, 8, 1, 3 (элементы на чётных позициях)
- `OfType<string>()` из `{ 1, "text", 2, "other" }`: "text", "other"
- `Cast<int>()`: 1, 2, 3

---

## 2. Проекция

| Метод | Что делает | Что принимает |
|---|---|---|
| `Select(u => u.Name)` | Преобразует каждый элемент в другое значение | `Func<T,TResult>` |
| `Select((u, i) => $"{i}: {u.Name}")` | То же, но с индексом | `Func<T,int,TResult>` |
| `SelectMany(t => t.Members)` | Разворачивает вложенные коллекции в одну плоскую | `Func<T,IEnumerable<TResult>>` |

Результаты в коде:
- `Select` имён: Анна, Иван, Олег, Анна
- `Select` с индексом: "0: Анна", "1: Иван", ...
- `SelectMany` по командам: Анна, Олег, Иван

---

## 3. Сортировка

| Метод | Что делает | Что принимает |
|---|---|---|
| `OrderBy(u => u.Age)` | По возрастанию | `Func<T,TKey>` |
| `OrderByDescending(u => u.Name)` | По убыванию | `Func<T,TKey>` |
| `ThenBy(u => u.Name)` | Вторичная сортировка после `OrderBy` | `Func<T,TKey>` |
| `Reverse()` | Переворачивает порядок | ничего |
| `Order()` | Сортировка без ключа (для чисел, строк и т. п.) | ничего |

Результаты в коде:
- `OrderBy` по возрасту: Иван(17), Анна(20), Анна(25), Олег(30)
- `Reverse` для `numbers`: 3, 9, 1, 2, 8, 2, 5
- `Order` для `numbers`: 1, 2, 2, 3, 5, 8, 9

---

## 4. Кванторы (возвращают `bool`)

| Метод | Что делает | Что принимает |
|---|---|---|
| `Any(u => u.Age >= 18)` | Есть ли хотя бы один подходящий элемент | `Func<T,bool>` |
| `All(u => u.Age >= 18)` | Подходят ли все элементы | `Func<T,bool>` |

Результаты в коде: `Any` возраста 18+ даёт `true`, `All` даёт `false` (Иван 17), `Any` по городу Москва даёт `true`.

---

## 5. Агрегация

| Метод | Что делает | Что принимает |
|---|---|---|
| `Count()` | Количество элементов | ничего |
| `Sum(u => u.Age)` | Сумма | `Func<T,число>` |
| `Min(u => u.Age)` | Минимум | `Func<T,TKey>` |
| `Max(u => u.Age)` | Максимум | `Func<T,TKey>` |
| `Average(u => u.Age)` | Среднее | `Func<T,число>` |
| `Aggregate("W", (acc, n) => acc + "J" + n)` | Своя свёртка: на каждом шаге `acc = func(acc, элемент)` | начальное значение + `Func<TAcc,T,TAcc>` |

Результаты в коде: Count = 4, Sum = 92, Min = 17, Max = 30, Average = 23.

`Aggregate` даёт `"WJ5J2J8J2J1J9J3"` (в комментарии кода написано `"5282193"`, это неточно: начальное значение `"W"` и буква `"J"` тоже попадают в строку).

---

## 6. Операции над множествами

| Метод | Что делает |
|---|---|
| `Distinct()` | Убирает дубликаты |
| `Union(other)` | Объединение без дубликатов |
| `Intersect(other)` | Общие элементы |
| `Except(other)` | Элементы первой, которых нет во второй |

Результаты в коде (`numsA = {1,2,3}`, `numsB = {3,4,5}`): `Distinct` для `numbers` даёт 5, 2, 8, 1, 9, 3; `Union` даёт 1, 2, 3, 4, 5; `Intersect` даёт 3; `Except` даёт 1, 2.

---

## 7. Соединения

| Метод | Что делает | Что принимает |
|---|---|---|
| `Join(cities, user => user.City, city => city.City, (user, city) => ...)` | Inner join: только пары с совпавшим ключом | вторая коллекция, два селектора ключа, функция результата |
| `GroupJoin(users, city => city.City, user => user.City, (city, cityUsers) => ...)` | Для каждого элемента первой коллекции даёт группу совпавших из второй | то же; функция результата получает `(элемент, группа)` |
| `Zip(names, (n, name) => ...)` | Попарно объединяет элементы по позиции | вторая последовательность + `Func<T1,T2,TResult>` |

Результаты в коде:
- `Join`: Анна/Москва, Олег/Москва, Иван/СПб (Анны из Казани нет, потому что Казани нет в `cities`)
- `Zip` чисел и имён: "5:Анна", "2:Иван", "8:Олег", "2:Анна" (длина равна более короткой последовательности)

## 8. Разбиение

| Метод | Что делает | Что принимает | Результат на `numbers` |
|---|---|---|---|
| `Take(3)` | Первые N | `int` | 5, 2, 8 |
| `Skip(2)` | Пропускает первые N | `int` | 8, 2, 1, 9, 3 |
| `TakeLast(2)` | Последние N | `int` | 9, 3 |
| `SkipLast(2)` | Пропускает последние N | `int` | 5, 2, 8, 2, 1 |
| `TakeWhile(n => n < 8)` | Берёт, пока условие истинно, и останавливается на первом ложном | `Func<T,bool>` | 5, 2 |
| `SkipWhile(n => n < 8)` | Пропускает, пока условие истинно, потом отдаёт всё остальное | `Func<T,bool>` | 8, 2, 1, 9, 3 |
| `Chunk(2)` | Делит на массивы по N элементов | `int` | [5,2], [8,2], [1,9], [3] |

## 9. Элементы последовательности

| Метод | Что делает | Если не найдено |
|---|---|---|
| `First()` / `First(n => n % 2 == 0)` | Первый элемент (подходящий под условие) | исключение |
| `FirstOrDefault()` | То же | значение по умолчанию (0 для `int`) |
| `Last()` | Последний элемент | исключение |
| `Single()` | Единственный элемент (если их не один, ошибка) | исключение |
| `SingleOrDefault()` | Единственный или значение по умолчанию | значение по умолчанию |
| `ElementAt(2)` | Элемент по индексу | исключение |
| `ElementAtOrDefault(100)` | Элемент по индексу | значение по умолчанию |
| `DefaultIfEmpty(100)` | Для пустой последовательности возвращает её с одним значением 100 | |

Результаты в коде: `First` = 5, первый чётный = 2, `Last` = 3, `Single` для `{42}` = 42, `ElementAt(2)` = 8, `ElementAtOrDefault(100)` = 0.

---

## 10. Преобразование типов

| Метод | Что делает | Что принимает |
|---|---|---|
| `ToArray()` | В массив | ничего |
| `ToList()` | В `List<T>` | ничего |
| `ToDictionary(u => u.Name, u => u.Age)` | В словарь. В коде закомментирован: ключ "Анна" повторяется, будет ошибка | селектор ключа и значения |
| `ToLookup(u => u.Name)` | Как словарь, но дубликаты ключей допустимы (`lookup["Анна"]` даёт две записи) | селектор ключа |
| `ToHashSet()` | В `HashSet<T>`, уникальные значения: {5, 2, 8, 1, 9, 3} | ничего |
| `AsEnumerable()` | Просто приведение к `IEnumerable<T>` | ничего |

---

## 11. Группировка

`GroupBy(u => u.City)` принимает `Func<T,TKey>` и возвращает группы. У каждой группы есть `Key` (город) и элементы, которые можно посчитать через `Count()`.

Результат в коде: Москва: 2, СПб: 1, Казань: 1.

---

## 12. Генерация

| Метод | Что делает | Результат |
|---|---|---|
| `Enumerable.Range(10, 3)` | Числа подряд: начало, количество | 10, 11, 12 |
| `Enumerable.Repeat("Hi", 2)` | Повторяет значение N раз | "Hi", "Hi" |
| `Enumerable.Empty<string>()` | Пустая последовательность | |

## 13. Прочие

| Метод | Что делает | Что принимает |
|---|---|---|
| `Concat(other)` | Склеивает две последовательности | последовательность |
| `Append(42)` | Добавляет элемент в конец | элемент |
| `Prepend(0)` | Добавляет элемент в начало | элемент |
| `SequenceEqual(other)` | Равны ли последовательности поэлементно | последовательность |

Результаты в коде: `Concat` даёт 5, 2, 8, 2, 1, 9, 3, 99, 100; `SequenceEqual` для одинаковых массивов даёт `true`.

## Отложенное выполнение

```csharp
var query = users.Where(u => u.Age > 18);   // запрос только описан, не выполнен
users.Add(new User("Петр", 40, "Минск"));   // меняем исходную коллекцию
var result = query.ToList();                // выполняется только здесь
```

Запрос выполняется в момент `ToList()` (или `foreach`), поэтому Петр попадает в результат. Подходят Анна(25), Олег(30), Анна(20) и Петр(40), то есть `result.Count` равен 4 (в комментарии кода написано 3, это неточно).

**IQueryable** (в коде только в комментарии): `dbQuery.Where(u => u.Age > 18)` строит дерево выражений `Expression`, а не делегат. Оно переводится, например, в SQL.

## record

```csharp
public record Product
{
    public string Name { get; init; }
    public decimal Price { get; init; }
    public Product(string name, decimal price) => (Name, Price) = (name, price);
}
public record struct Point(int X, int Y);
public record Person(string FirstName, string LastName, int Age);
```

| Возможность | Описание |
|---|---|
| `record Person(...)` | Короткая запись: компилятор сам создаёт конструктор и свойства |
| `init` | Свойство задаётся только при создании объекта, потом неизменяемо |
| Конструктор в `Product` | Написан вручную, присваивает свойства через кортеж `(Name, Price) = (name, price)` |
| `person1 == person2` | Сравнение **по значениям** свойств, даёт `True` |
| `person1 with { Age = 31 }` | Копия с изменённым свойством, оригинал не меняется |
| `var (first, last, age) = person1;` | Деконструкция: first = "John", last = "Doe", age = 30 |
| `record struct Point(int X, int Y)` | То же для значимого типа; `p1 with { Y = 30 }` даёт точку (10, 30) |
